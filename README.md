# Anniversary Scrapbook

An interactive 5-month anniversary celebration with flip cards, word search, and jigsaw puzzle!

## Features
- 🎨 Flip cards with sweet messages
- 🔍 Word search puzzle with hidden phrases
- 🧩 Interactive jigsaw puzzle with confetti celebration
- ✨ Smooth animations and interactive elements
- 📱 Mobile responsive design

## How to Use
1. Open the live link in your browser
2. Click flip cards to reveal messages
3. Click grid letters to find hidden words
4. Drag puzzle pieces to complete the image
5. Complete the puzzle to see confetti! 🎉
